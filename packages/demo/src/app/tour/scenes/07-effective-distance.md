Far-away elements on DNA—like a gene and an element that regulates it—often need to visit each other. Rather than wander around randomly in space and hope to meet, loop extrusion makes the search process much more efficient. 

CTCFs play an important role in orchestrating this transit system, helping some elements rendezvous frequently and others less.

---

We can estimate this effect by calculating an "effective 1D distance" between any pair of elements, by tracing the shortest path between them along the lattice, hopping across loops. **Encounters** happen when the effective distance is short enough.
